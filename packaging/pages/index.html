OPC UA Manager

Windows client for browsing, monitoring and testing OPC UA servers.

Download the latest release (installer and portable ZIP).

Installed copies receive updates automatically through the Maintenance Tool from the update repository at updates/stable/ on this site.

Source code: download Source code (zip) from the release page or clone the repository on GitHub, then build it with CMake or produce your own installer; see Installation.

Windows installation notice

OPC UA Manager is a young open-source project and is currently distributed without a digital code-signing certificate. Microsoft Edge, Microsoft Defender SmartScreen, or Windows may therefore warn about an unknown publisher or an unrecognized file when downloading or running the installer. This is expected for the current releases and does not by itself indicate that the installer contains malicious software.

If Windows blocks the download or the start of the installer, use the options Windows provides for unrecognized applications (for example More info → Run anyway). Step-by-step instructions and how to check the SHA-256 digest of a download are in the project README.
